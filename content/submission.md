# راهنمای تحویل

## بسته تحویل تیم

- لینک سورس GitHub و commit یا tag مشخص نهایی.
- Backend قابل ساخت و اجرا با زبان و فریم‌ورک انتخابی تیم و پایگاه داده رابطه‌ای.
- Migration و Seed Data قابل تکرار؛ راهنمای محیط و متغیرهای لازم بدون secret واقعی.
- OpenAPI / Swagger مطابق رفتار اجرا و آدرس نسخه قابل استفاده Frontend.
- README با دستور دقیق اجرا، اعمال migration و seed، ساختار ساختار پروژه و تصمیم‌ها.
- قابلیت‌های کامل و ناقص، محدودیت‌ها، تست‌های نوشته‌شده و روش اجرای آن‌ها.
- شواهد شش سناریوی ارائه در بخش ۲۳ متن اصلی.

## مسیر ارائه پیشنهادی

ثبت‌نام و ورود → دعوت عضو و کنترل نقش → ایجاد Holding صفر → واریز → خرید و فروش → رد برداشت بیش از موجودی → داشبورد → رد دسترسی به Workspace دیگر. با داده قابل reset اجرا کنید و تغییر واقعی موجودی را نشان دهید.

## سؤال‌های README شرکت‌کننده

نسخه SDK چیست؟ سرویس چگونه اجرا می‌شود؟ اتصال دیتابیس با چه متغیری تنظیم می‌شود؟ migration چگونه اعمال می‌شود؟ seed چگونه ساخته می‌شود؟ ساختار و تصمیم‌های فنی چیست؟ کدام قابلیت‌ها کامل‌اند؟ چه محدودیت‌هایی باقی است؟ تست چگونه اجرا می‌شود؟

زمان شروع تقویمی، مهلت ساعت تحویل، لینک Figma و اطلاعات تماس در متن دریافتی مشخص نشده‌اند. این پرتال عدد یا لینک ساختگی برای آن‌ها اعلام نمی‌کند؛ روزها نسبی‌اند. پس از اعلام رسمی، این اطلاعات باید در PR جدا به‌روز شوند.
