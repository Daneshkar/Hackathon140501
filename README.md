# هکاتون زمستان ۱۴۰۵ دانشکار

مرجع فارسی مسیر Backend پروژه **Daneshkar Digital Asset Management Platform** برای توسعه‌دهندگان Junior؛ چهارده روز از تحلیل تا تحویل، با امتیاز ۱۰۰ پایه + ۳۰ ویژه.

این مخزن شامل پرتال RTL، نقشه Adventure تعاملی، متن جامع سناریوی برگزارکننده، قرارداد OpenAPI، معیارهای پذیرش و راهنمای همکاری است. پیاده‌سازی Backend و دیتابیس وظیفه تیم‌هاست. تراکنش‌ها شبیه‌سازی‌اند و اتصال به بلاکچین یا انتقال واقعی لازم نیست.

## اجرای محلی پرتال

Node.js نسخه ۲۲ یا جدیدتر کافی است؛ بسته جانبی لازم نیست.

```sh
npm run build
npm run check
npm test
npm run dev
```

سپس http://127.0.0.1:4173 را باز کنید. فایل‌های `docs/` آمادهٔ میزبانی ایستا هستند. نقشه شامل ۱۴ مأموریت در چهار منطقه است؛ روز ۸ تا ۱۰ «یکپارچگی» و ۱۱ تا ۱۴ «انتشار» در نمایش گرافیکی است. ترتیب و فعالیت‌ها مطابق نقشه راه متن اصلی باقی مانده‌اند.

پیشرفت فقط در localStorage همان مرورگر ذخیره می‌شود. خروجی و بازیابی JSON برای جابه‌جایی دستگاه موجود است. سایت اطلاعات پیشرفت را به سرور ارسال نمی‌کند. در نبود JavaScript، همه محتوا و روزها در صفحه سناریو قابل مطالعه‌اند.

## ساختار مخزن

`scenario-source.md` متن دریافتی برگزارکننده؛ `content/` منابع تکمیلی و داده نقشه و امتیازها؛ `scripts/` تولید و بررسی؛ `docs/` خروجی قابل انتشار و دارایی‌ها؛ `tests/` آزمون‌های پرتال؛ `.github/workflows/` اعتبارسنجی PR و انتشار Pages.

سناریوی اصلی مرجع نیازمندی‌هاست. قرارداد API جزئیات اجرایی پیشنهادی مانند هدر Workspace، شکل decimal، صفحه‌بندی، خطا و وضعیت فقدان قیمت را صریح می‌کند. این جزئیات، موضوع و وزن‌های سناریو را تغییر نمی‌دهند. لینک Figma و تاریخ تقویمی شروع در داده ارسالی وجود نداشته و جعل نشده است.

## انتشار

پس از PR و موفقیت بررسی‌ها، تغییرات وارد main شوند. در Settings → Pages، Source را GitHub Actions قرار دهید. workflow `pages.yml` ابتدا ساخت، بررسی لینک‌ها و آزمون‌ها را انجام می‌دهد، سپس فقط `docs/` را با محیط `github-pages` منتشر می‌کند. PR هیچ مجوز انتشار یا secret ندارد. راهنمای کامل و روش جایگزین در [DEPLOYMENT.md](DEPLOYMENT.md) است.

## فناوری مورد انتظار تیم‌های Backend

C#، ASP.NET Core Web API، EF Core، SQL Server یا PostgreSQL، REST، OpenAPI و Git الزامی‌اند. JWT پیشنهاد اصلی است. Clean Architecture، CQRS، تست خودکار، داده بازار خارجی، کنترل پیشرفته هم‌زمانی و Idempotency، Docker و CI و امنیت پیشرفته امتیاز ویژه دارند؛ قبل از MVP سراغ پیچیدگی اضافی نروید.

برای تغییر محتوا [راهنمای مشارکت](CONTRIBUTING.md) را بخوانید. این مخزن فعلاً مجوز متن‌باز جداگانه‌ای تعیین نکرده است؛ عمومی‌بودن آن به معنی اعطای مجوز دلخواه نیست.
